# tile-ooo ISA v0.1 — 标量子集

> 状态：冻结底稿（里程碑 0 交付物）
> 与实现一致：[rtl/core/isa_pkg.sv](../../rtl/core/isa_pkg.sv) 与 [tools/isa.py](../../tools/isa.py)

## 1. 基本约定

- 指令定长 **32 bit**；程序计数器 PC 按「**字**」寻址（1 字 = 1 条指令，非字节）。
- 标量寄存器 **x0..x31**，各 32 bit；**x0 恒为 0**（读恒 0，写被忽略）。
- 立即数一律 **12 bit 有符号**，先符号扩展至 32 bit 再参与计算。

## 2. 位段总览

每条指令的 bit[6:0] 恒为 opcode，其余字段依指令类型（I/R/B/J）而定：

| 格式 | [31:20] | [19:15] | [14:12] | [11:7] | [6:0] |
| --- | --- | --- | --- | --- | --- |
| **I 型**（ADDI/LD） | imm[11:0] | rs1 | funct3 | rd | opcode |
| **R 型**（ADD/SUB） | funct7[6:0] ++ rs2[4:0] | rs1 | funct3 | rd | opcode |
| **B 型**（BEQ/BLT） | imm[11:0] | rs1 | funct3 | **rs2** | opcode |
| **ST** | imm[11:0] | rs1 | funct3 | **rs2** | opcode |
| **J 型**（JMP） | imm[11:0] | 0 | 0 | 0 | opcode |

> R 型中 funct7 占 [31:25]、rs2 占 [24:20]，合起来是 [31:20]。
> 与 RISC-V 原版不同，这里**所有立即数统一落在 [31:20]**；代价是分支的 rs2 挪到 [11:7]
> （分支不写回，rd 位段本就空置），换来译码与理解上的统一。

## 3. 指令汇总

| 指令 | 语义 | opcode | funct3 | funct7 |
| --- | --- | --- | --- | --- |
| `ADDI rd, rs1, imm` | rd = rs1 + sext(imm) | `0x13` | `0x0` | — |
| `ADD rd, rs1, rs2` | rd = rs1 + rs2 | `0x33` | `0x0` | `0x00` |
| `SUB rd, rs1, rs2` | rd = rs1 − rs2 | `0x33` | `0x0` | `0x20` |
| `LD rd, imm(rs1)` | rd = mem[rs1 + sext(imm)] | `0x03` | `0x0` | — |
| `ST rs2, imm(rs1)` | mem[rs1 + sext(imm)] = rs2 | `0x23` | `0x0` | — |
| `BEQ rs1, rs2, imm` | 若 rs1 == rs2，PC += imm | `0x63` | `0x0` | — |
| `BLT rs1, rs2, imm` | 若 rs1 < rs2（有符号），PC += imm | `0x63` | `0x4` | — |
| `JMP imm` | PC += imm（无条件） | `0x6F` | — | — |
| `HALT` | 停机 | `0x7F` | — | — |

区分规则：

- `ADDI` 与 `ADD/SUB` 靠 **opcode** 区分（`0x13` vs `0x33`）。
- `ADD` 与 `SUB` 靠 **funct7** 区分（`0x00` vs `0x20`）。
- `BEQ` 与 `BLT` 靠 **funct3** 区分（`0x0` vs `0x4`）。
- `LD` 与 `ST` 靠 **opcode** 区分（`0x03` vs `0x23`）；funct3 固定 `0x0`（本阶段仅字宽访问）。

## 4. 立即数、分支与访存语义

分支与跳转的立即数是**字偏移**，相对**该指令自身的地址**计算：

```
目标地址 = 当前指令地址 + sext(imm)
```

- 正数向后跳，负数向前跳；不做边界检查，超出指令存储器范围即环绕（与 8-bit 地址模加一致）。
- 分支命中会造成 1 拍流水线冲刷（被取进流水线的顺序后继指令作废为 NOP）。

访存地址同样来自 **rs1 + sext(imm)**，按**字**寻址，取低 6 位（对 64 字 = 256B 数据存储器取模）。`LD` 读数据存储器写回 rd；`ST` 把 rs2 写入数据存储器、不写回寄存器。数据存储器上电清零，未写入位置读到 0。

## 5. 未实现 / 非法编码

- 全 0 字（opcode = 0）即 **NOP**：不写回、不跳转、PC 顺序 +1。
- 其他**未实现的 opcode 当前一律按 NOP 处理**，不触发异常（本阶段尚无非法指令陷阱）。
- 写入 **x0 一律忽略**，保证 x0 恒 0。
- Python 参考模型遇到未实现指令会抛出错误，用于在差分测试中尽早暴露编码笔误。

## 6. 示例程序

计算 `x3 = (5 + 5)`，验证 BEQ：设 x1=x2=5，命中后跳过一条指令。

| 地址 | 汇编 | 机器码 |
| --- | --- | --- |
| 0 | `ADDI x1, x0, 5` | `0x00500093` |
| 1 | `ADDI x2, x0, 5` | `0x00500113` |
| 2 | `BEQ x1, x2, +2` | `0x00208163` |
| 3 | `ADDI x3, x1, 1`（被跳过） | `0x00108193` |
| 4 | `ADDI x3, x1, 4` | `0x00408193` |
| 5 | `HALT` | `0x0000007F` |

结果：`x1 = 5`，`x2 = 5`，`x3 = 9`（跳过了地址 3）。
